📋 Descripción del cargo

En Tech Solutions S.A.S buscamos un Desarrollador Frontend apasionado por crear interfaces modernas, accesibles y de alto rendimiento. Trabajarás junto a un equipo multidisciplinario para construir productos digitales utilizados por miles de personas en toda Colombia.

Esta es una posición 100% remota. Valoramos la autonomía, la comunicación asertiva y las ganas de aprender y aportar en un ambiente de trabajo flexible y en constante evolución.

Serás parte de un equipo ágil que trabaja con metodologías Scrum, iteraciones de dos semanas y una cultura de retroalimentación continua. El impacto de tu trabajo será visible desde el primer día.

🎯 Responsabilidades
  • Desarrollar y mantener componentes de interfaz reutilizables con React y TypeScript.
  • Colaborar con el equipo de diseño para implementar mockups de forma fiel y accesible.
  • Optimizar el rendimiento de la aplicación (Core Web Vitals, lazy loading, code splitting).
  • Escribir pruebas unitarias y de integración con Jest y Testing Library.
  • Participar en revisiones de código y contribuir a la mejora continua del equipo.
  • Documentar los componentes y mantener Storybook actualizado.
  • Participar en las reuniones de planificación y retrospectivas del equipo Scrum.
✅ Requisitos
  • 2+ años de experiencia en desarrollo frontend con React.
  • Dominio de HTML5, CSS3 (Flexbox, Grid) y JavaScript ES6+.
  • Experiencia con TypeScript y manejo de estado (Redux, Zustand o similar).
  • Conocimiento de principios de accesibilidad web (WCAG 2.1).
  • Capacidad para trabajar de forma autónoma y en equipo remoto.
  • Nivel de inglés intermedio para lectura técnica.
⭐ Deseable (no excluyente)
  • Experiencia con Next.js o Vite.
  • Conocimiento básico de Node.js o consumo de APIs REST/GraphQL.
  • Portafolio o repositorio público en GitHub.
  • Experiencia con herramientas de diseño como Figma o Zeplin.
